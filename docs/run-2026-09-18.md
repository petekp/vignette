### A double-click with the select tool zooms
`todo6/zoom`, `f67164e`.

sends it only when the tool is `select`, nothing is being edited, and
`editor.getShapeAtPoint(…, { margin: getHitTestMargin(), hitInside: false })` finds nothing. The
screenshot is locked and locked shapes are not hit-tested, so anything that comes back is a mark.
The host treats the message exactly as the trackpad's two-finger double tap.
`createTextOnCanvasDoubleClick: false` stops tldraw adding a text shape on the same double-click.

refusals zoom left open (section 2).

### The stand-in behind a seam of its own
`todo6/cleanup`, `f358674`.

`StandInController` (in `Sources/StandIn.swift`, beside the `StandIn` view it drives) owns the
picture and its generation counter, the two images, the overlay throttle, the `setView` hand-over

### The app carries the agent skill and installs it
`todo6/skill`, `87ad165` and `76b4bd4`.

`skills/shotnote/SKILL.md` is the skill's home in the repo and a folder resource in the bundle
(`project.yml`), so the version that answers the commands is the version that teaches them.

`Sources/SkillInstaller.swift` is a pure piece with everything as a parameter. A root is an agent's
own directory (`.claude`, `.codex`) and only one that exists; the skill lands in
`<root>/skills/shotnote`. `.shotnote-skill.json` beside it names the app, version and build.
`state(of:)` reads the path with `attributesOfItem`, which does not follow links, so a symlink is
foreign whatever it points at, and anything foreign is never written and never removed. Our own copy
is rewritten when the stamp differs from this build **or** the files differ from the bundle's.

`agentSkill` in settings.json is `unasked`, `on` or `off`, stored as a string and clamped in
`validated()`. `on` installs and keeps the copy current at every launch, `off` removes it, and
`unasked` with an agent directory present makes the offer once: the Settings window at a new Agents
section, since a toast carries no button. Making the offer records `off`, so it happens once
whatever the user does. The Settings window is now capped at the screen's visible height and the
form scrolls inside it, because without that cap the Agents section hung off the bottom of this
982-point screen — the offer would have opened a window whose answer could not be reached.

`shotnote://install-skill` installs into every agent directory and sets the key to `on`; with
`&root=<dir>` (debug only) it installs into that one directory and leaves the setting alone, which
is what let this be checked live without ever writing a real root. `app.agentSkill` in the state
report is `{"setting": …, "installed": [paths]}`.

Not verified by anyone: the toggle switched on in a live round, and removal, because both write into
the real `~/.claude` and `~/.codex`. Both paths are unit-tested (9 tests) and the command exercised
the same `applyAgentSkill`/`SkillInstaller` code.

## 2. Decisions made without you, and open questions

### The strip
- **16 points** is strip's reading of "a bit more". The slider is in the tweak panel under Cards.
- **The gap is measured from the widest *selected* card, not the column's widest.** The strip still
  steps 68 points sideways when a wider card joins the selection. Strip left that on purpose: the
  strip says which cards it acts on by being beside them, and measured from the column it would hang
  68 points off a narrow selected card with nothing in between. One line in `stripPlacement` changes
  it if you would rather it stood still.

### The zoom
- **Your settings file has `zoomEdgeBand: 0.41`, which the rename makes dead**, and
  `zoomEdgePull: 0.6`, which is kept. My round confirmed both: the tweak panel read
  **Zoom edge band 120pt** and **Zoom edge pull 0.60** on a scratch file seeded from yours. On a
  986 x 689 frame your 0.41 reached 404 points across and 282 down, so 120 will feel much less
  sticky. About **250 to 300 points** is the closest match; the slider goes to 400. Delete the old
  line.
- **The band is in points rather than a fraction of the shorter side.** Both make the four edges
  agree; a fraction reaches a different distance on a 3:1 screenshot than on a square one, and it is
  not a unit a slider can label.
- **A double-click inside an unfilled rectangle zooms.** tldraw does nothing there, so as far as the
  editor is concerned it is empty canvas. I drove this and it does zoom (section 2, below). If you
  expect a mark's whole box to be the mark, the rule becomes `hitInside: true`, at the cost of a
  dead zone inside every large rectangle.
- **tldraw's double-click-to-add-text on the canvas is off.** The text tool is unaffected.

### The palette and the cleanups
- **The palette is gone from the code, not hidden behind a flag.** If you ever wanted the swatches
  as a developer-only thing, say so now: it is a rewrite, not a constant, once this lands.
- **A web process restart while zoomed leaves the window grown and the page at camera 1** until the
  next zoom input. Cleanup found this and confirmed it is pre-existing, not from this branch.
- **The protocol is 11 and D3 shares the palette's bump** rather than taking a 12 of its own.

### The agent skill
- **The offer fires on `agentSkill: unasked`, not on `settings.firstLaunch`.** Taken literally,
  "on first launch" would mean every existing install, yours included, carries `unasked` forever and
  is never asked. The cost is that the first launch of this build activates the app once, to show the
  Settings window. If that is wrong at login after an update, it is one line in `offerAgentSkill`'s
  caller.
- **On this Mac `~/.claude/skills` is a symlink into a git repository of yours**
  (`~/Code/claude-code-setup/skills`). Turning the toggle on writes an untracked `shotnote/`
  directory inside that repository. The marker rule protects a copy *you* made; it does not stop the
  app writing a new one into a linked `skills` directory. The behaviour was left as it is. If that is
  wrong, the rule to add is "refuse a root whose `skills` is itself a link". `~/.codex/skills` is a
  real directory, so it has no such problem.
- **Nothing publishes the skill on skills.sh**; that TODO still waits on the public repo.

### Mine, as integrator
- **The scratch settings file was seeded from yours, which pins `selectionStripGap` to 8.** A file
  value wins over a default, so the first reading of the tweak panel showed 8 and not the new 16. I
  deleted the key from the scratch file so that the round exercised the merged default. Your own file

- **I did not switch the skill toggle on**, on any settings file, for the same reason skill did not:
