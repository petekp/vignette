Sending to Claude Code without herdr: the edge cases

A sketch for docs/claude-code-without-herdr-2026-09-27.md. It shows where the notes and states would appear. Session names are invented and the wording is a draft.

1. Choosing a session that asks first

The target next to Send opens the list of recent sessions. A session that runs with permission prompts off gets a second line, so you know before sending that it will ask you to approve the drawing in its terminal.

2. After Send, on the card

The card the drawing came from reports, as it does now. Clicking a card opens it in the editor, so going to the session is a button on the card, not a click on the card.

3. A Claude Code update Vignette doesn't support yet

Vignette checks each session's messaging version when it lists them. Nobody finds out by losing a drawing.

4. The help page behind Learn More

One page in Vignette’s guide, “Sending to Claude Code”, with a section for each case: sessions that ask first, a drawing that wasn’t taken, and a Claude Code version Vignette doesn’t support yet. Each Learn More opens its own section. The page explains the Claude Code setting in full and links to Anthropic’s cross-session messaging docs, so the text in the app stays short. The page can change without a new Vignette, for example on the day a Claude Code release breaks sending.

Wording is a draft. It goes through the copy review before it's built.
